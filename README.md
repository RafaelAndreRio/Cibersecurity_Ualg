# Postgraduate Portfolio

This repository serves as a portfolio showcasing the work and projects completed during my postgraduate studies. It includes materials and documentation related to various disciplines, demonstrating the knowledge, skills, and practical applications acquired throughout the program.

## Included Disciplines

- **Cybersecurity Assessment, Penetration Testing, and Auditing**  
- **Forensic Analysis of Computer Systems**  
- **Cybersecurity in Systems Administration**  
- **Cybergovernance, Risk Management, Compliance, and Standards**

## Purpose

The portfolio is intended to:  
- Present the work carried out during the postgraduate courses.  
- Document projects, exercises, and practical applications related to each discipline.  
- Serve as a professional showcase of acquired competencies in the field of cybersecurity and IT governance.

## Navigation

Each discipline is organized into separate folders containing:  
- Reports, analyses, and project files  
- Code samples (if applicable)  
- Supporting documentation and references
